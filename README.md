# Description

1. Employee Salary System
Barnaamijkan waxaa loo sameeyay in lagu xisaabiyo mushaharka shaqaalaha kala duwan ee shirkad. Wuxuu soo bandhigayaa xogta shaqaalaha sida aqoonsiga, magaca, waaxda uu ka shaqeeyo iyo mushaharka uu qaato bishii.

Barnaamijku wuxuu ka kooban yahay afar class oo kala ah Employee, FullTimeEmployee, PartTimeEmployee iyo Manager. Fasalka Employee wuxuu hayaa xogta guud ee shaqaalaha, halka fasallada kale ay ka dhaxlaan xogtaas oo ay leeyihiin habab u gaar ah oo mushaharka loo xisaabiyo.

Shaqaalaha waqti buuxa shaqeeya mushaharkooda waxaa lagu daraa gunno, shaqaalaha waqti-dhiman mushaharkooda waxaa lagu xisaabiyaa saacadaha ay shaqeeyeen iyo lacagta saacaddii, halka maamulaha mushaharkiisa lagu daro gunno dheeraad ah.





2. Hospital Billing System
Barnaamijkan waxaa loo sameeyay in lagu xisaabiyo kharashka adeegyada caafimaadka ee isbitaalka. Wuxuu soo bandhigayaa magaca adeegga, aqoonsigiisa iyo lacagta laga bixinayo adeeg kasta, kadibna wuxuu isku daraa dhammaan kharashaadka si loo helo wadarta biilka.

Barnaamijku wuxuu ka kooban yahay fasalka MedicalService iyo saddex fasal oo kale oo kala ah Consultation, LaboratoryTest iyo Ultrasound. Fasalka MedicalService wuxuu hayaa xogta guud ee adeegyada caafimaadka, halka fasallada kale ay xisaabiyaan kharashka adeeg kasta.
